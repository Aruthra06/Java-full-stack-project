### 🚀 Quick Start Commands

1. **Setup Database:**
   ```bash
   # Run MySQL and execute:
   source database/schema.sql
   ```

2. **Start Backend:**
   ```bash
   cd backend
   mvn spring-boot:run
   ```

3. **Open Frontend:**
   ```bash
   # Open frontend/index.html in browser
   # Or use: cd frontend && npx http-server -p 3000
   ```

4. **Alternative - Run Setup Script:**
   ```bash
   # Double-click setup.bat (Windows)
   ./setup.bat
   ```
